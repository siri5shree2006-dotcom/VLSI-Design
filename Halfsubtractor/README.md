# Half Subtractor

## Description
A Half Subtractor is a combinational logic circuit used to subtract two 1-bit binary numbers.

## Inputs
- **A** – Minuend
- **B** – Subtrahend

## Outputs
- **Difference** – Result of subtraction
- **Borrow** – Borrow generated during subtraction

## Logic
- Difference = A XOR B
- Borrow = NOT A AND B
