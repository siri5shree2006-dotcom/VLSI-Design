# VLSI Design Lab

Welcome to my VLSI Design Lab — a collection of hardware designs developed while learning and exploring digital electronics, Verilog HDL, RTL design, and FPGA/VLSI concepts.

## About

This repository contains my implementations of digital circuits and RTL designs, starting from fundamental combinational logic and gradually progressing toward more advanced digital systems.

Each design is developed, simulated, and documented as part of my hands-on learning.

## Includes

- Combinational Logic
- Sequential Logic
- FSM
- Memory
- Communication Protocols
- RTL Design
- FPGA


## Tools

- Verilog
- SystemVerilog
- Vivado

## Current Work

- Half Adder
- Full Adder
- Full Adder using Half Adders
- Multiplexer
- Demultiplexer

 As I learn further  and more will be added. This repository is continuously updated with new designs.
